Coding Challenge: Todo App with FastAPI
Goal
Develop a RESTful API for a Todo application using FastAPI. The API should provide basic CRUD operations and include a reminder function for upcoming tasks. Feel free to implement your own ideas or additional functionality to provide
a little bit more valuable information for the review of the coding challenge :).

Requirements
Technology Stack:

Backend: Python with FastAPI
Database: MariaDB or MySQL
Database Migrations: Alembic
Containerization: Docker & Docker Compose
Optional: Redis and a queue for reminders

API Functionality:

CRUD for Todos:

Create a new Todo
Retrieve a specific or all Todos
Update a Todo
Delete a Todo


Reminder Function:

Ability to set a reminder time for a Todo
Optional: Use Redis and a queue for managing reminders



Additional Requirements:

The API should follow RESTful principles.
All endpoints should return meaningful HTTP status codes.
Use Pydantic for request and response models.
API documentation should be available via OpenAPI (Swagger, automatically generated by FastAPI).
Basic error logging should be implemented.

Setup & Deployment:

The application should be fully operational with Docker and Docker Compose.
A README.md should include installation, usage instructions, and API documentation.
The challenge must be published in a public GitHub repository.


Evaluation Criteria:

Code Quality & Structure: Clear, modular, and well-documented implementation.
RESTful API Design: Proper use of HTTP methods, status codes, and endpoints.
Database Design & Migrations: Use of Alembic for database changes.
Error Handling & Logging: Proper handling of potential error cases and logging mechanisms.
Bonus: Implementation of Redis and a queue for reminders.


Good luck!
